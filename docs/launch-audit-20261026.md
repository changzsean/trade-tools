## 自动更新的实际边界

检查时有 76 条采集资料、51 条公开资讯，9 个启用信源抓取正常，自适应间隔约 60 分钟。新 API 和 worker 的发布版本 `20261026-site-updates1` 已通过心跳核验。

模型仍受原有滚动 24 小时最多 100 次请求约束，检查时有 21 条资料等待额度。下一批额度最早在北京时间 10 月 26 日 16:00 左右逐步释放，之后由 worker 继续处理，不保证每一条都会通过发布标准。日报等任务也使用模型额度。未提高额度、降低入选门槛、伪造新内容或重置调用记录。

页面每 5 分钟检查已发布内容，不等于每 5 分钟必定产生新闻；单篇详情也不会自动变成另一篇文章。

- 资讯后台：`npm run typecheck` 通过，`npm test` **947/947 通过、无跳过**。数据库测试使用独立本地 PostgreSQL，包含备份及恢复；本地恢复测试不能替代线上异地备份演练。
- 资讯框架网页：生产构建通过；Chromium + WebKit **60/60 通过、无跳过**。修正测试里遗留的旧示例分类名“模型/产品”为本站“AI动态/新产品”。
- 主站：`npm run typecheck`、`npm test`（6/6）、生产构建通过。
- 主站线上 `node scripts/smoke.ts --base https://meeka.com.cn --require-editorial`：15 个入口及一篇真实编辑稿正文、作者与来源检查全部通过。
- 生产浏览器：注册未同意被拦截、同意后发送正确版本、找回密码回跳地址正确、恢复事件后显示表单、密码不一致被拦截、模拟密码更新后要求重新登录；未发送真实邮件、未修改真实账号密码。
- 实际登录服务：不存在的测试账号正常返回 400 invalid_credentials，证明认证服务可达，不能据此宣称已验收真实账号全流程。
- 主站会员库安全建议已无 ERROR，剩余 pg_trgm 扩展位置、泄露密码防护未开启两项 WARN；私有同意表启用 RLS 且无客户端策略为预期 INFO。资讯私有表的无 policy 提示也不应通过开放匿名权限消除。

初次浏览器回归曾遇到本机磁盘不足及旧分类断言失败；清理本任务临时数据、修正断言后完成 60/60，保留前后日志。没有清理用户业务文件。

## 核验限制

Supabase 连接工具没有 SMTP/认证配置管理能力；浏览器控制台读取两次超时，未能核实 SMTP 和回跳允许列表，不能用“页面做好了”替代实际收信。

后台独立 `*.vercel.app` 从本机直接探测超时，Vercel 完整日志/受保护链接工具仍受连接权限限制。主站服务端读取、READY、数据库和 worker 心跳正常，但这些不能替代当前匿名管理接口的 HTTP 权限验证；后续需补部署侧探测。管理 API 的认证规则未因本轮改动被放宽。

未进行真实支付、压测或攻击性渗透；生产数据未导出到公共位置。
