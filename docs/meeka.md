域名：`https://meeka.com.cn`。当前交付尚未切换正式域名。本地已手动采集32条真实材料，仍待模型处理。上线方案见hosting-plan.md，API配置见model-setup.md。

## 内容范围

- AI动态：新模型、研究、能力、价格、可用性与有证据的趋势，保留独立AI资讯。
- AI方法：提示词、工作流、自动化、实测教程与可复用框架。
- AI+外贸案例：客户研究、开发信、询盘报价、多语言营销、选品、跟单、售后的实施复盘。
- 外贸动态：进出口、关税、海关、认证、物流、平台规则与贸易趋势，无须包含AI。
- 市场机会：有国家/地区、品类、时间与数据支撑的需求或准入信号。
- 新产品：AI工具、外贸实体新品、品类创新与跨境服务，排除普通目录与招商口号。

分类键用于新站；保留 ai-models、ai-products、industry、tip，并新增 ai-trade、opportunity。paper/opinion已从新站分类移除。若有旧库，先备份并逐条处理历史分类，不要直接将此包覆盖正在运营的站。
原有内容类型、五维权重、噪声上限、安全边界和门槛保留。门槛未重新校准，不能据测试通过推断选稿准确。
案例优先说明任务、步骤、输入、成本、人工复核、效果与限制；不补造缺失信息。市场信号不等于订单，销售额不等于利润。

## 信源与试抓

11个初始配置，9个启用、2个停用。仅展示摘要和原文链接，全文与全文RSS均关闭。首次每源最多回填4条。

| 信源 | 状态与验证 |
|---|---|
| OpenAI、Google DeepMind、Microsoft Research、AWS ML、Simon Willison | 项目RSS采集器返回条目和日期 |
| WTO | 官方RSS试抓成功，返回10条及日期 |
| Amazon创新 | 官方RSS试抓成功，返回10条及日期 |
| 商务部首页 | 真实HTML可解析12条，详情页PubDate可补日期；列表栏目页由脚本加载，因此使用首页新闻节点 |
| Shopify最新文章 | 使用真实HTML列表而非返回网页的blog.atom；最新列表返回21条真实文章，详情页使用meta[itemprop=datePublished]补日期，首条日期2026-10-20已核对 |
| Hugging Face | 连续试抓失败，enabled=false；上线服务器试抓成功再启用 |
| 海关总署 | 原始页面可读且选择器可解析，但项目采集器返回HTTP 412，enabled=false；上线环境复核后启用 |

抓取结果是当次快照，不保证后续稳定可用。新闻的可信日期仍由引擎控制，缺日期先不公开。
信源配置只导入缺失项，不覆盖数据库中已有设置；从文件删除也不会停用存量源，旧站须到后台手工暂停不需要的源。
当前初始来源偏重官方动态和方法；特定品类新品、B2B获客案例和目标市场需求还需补充你确认的专业来源。尚未添加付费公众号、X或Jina服务。
