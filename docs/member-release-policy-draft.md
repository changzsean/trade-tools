## 拟定的服务范围

第一阶段提供免费的邮箱会员账号、个人公开资料、会员社区和资讯阅读。资讯栏目发布 meeka编辑部 独立整理的中文编辑稿，底部保留原始来源链接和日期。资源目录、成长等级等尚属预览时，明确标注，不承诺收费权益或虚构交付。

会员提交社区内容时须具备必要权利，并自行避免公开客户名单、商业秘密、个人敏感信息和无权传播的材料。运营者可处理侵权、垃圾信息、违法内容和明显虚假内容。对资讯和工具输出应自行核验，涉及交易、合规或专业决策时应寻求适当专业支持。

## 拟收集的数据与用途

- 邮箱及认证凭据由 Supabase Auth 处理，用于注册、验证、登录与密码恢复；网站业务表不保存明文密码。
- 用户名、显示名、头像链接、个人简介及会员角色存于会员数据库。其中用户名、显示名、简介、头像及内容署名可能被其他用户或访客看见；认证邮箱不通过公开资料接口展示。
- 帖子、问答、需求与评论按对应板块访问范围展示；私人收藏只允许所属账号读取。
- 搬品工具等功能按实际页面提示保存运行资料。仍仅存于浏览器的数据应明确标注，不能承诺换设备可恢复。
- 认证会话存于浏览器；基础访问与错误记录由托管服务用于运行和安全排查。不因注册默认订阅营销邮件。
- 新闻编辑后台使用 DeepSeek 处理采集的公开资料。不得宣称用户的所有会员资料都会发送给模型服务；会员工具若发送业务内容，另在实际使用前说明服务商和传输范围。

## 服务商、地区与保留

数据库与认证由 Supabase 托管，目前会员库区域为美国东部；网站由 Vercel 提供托管。使用这些服务可能涉及跨境数据处理。Cloudflare 的具体职责以最终启用资源为准，不能把尚未启用的 R2 写成已提供持久化保障。

拟保留账号资料直到用户请求注销或服务终止；运营者通过联系邮箱受理资料访问、更正、导出和删除请求，并核实请求者身份。删除时需评估业务关联、公开内容、法定保留要求和备份保留周期。当前尚无自助注销入口、已批准的固定处理时限或完整备份保留方案，不作自动删除或恢复保证。
